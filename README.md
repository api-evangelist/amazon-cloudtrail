# Amazon CloudTrail API

AWS CloudTrail is a service that enables governance, compliance, operational auditing, and risk auditing of your AWS account by recording API calls and delivering log files containing API activity for your account.

## APIs

- **Amazon CloudTrail API** - API for recording and monitoring AWS API calls made on your account. CloudTrail provides event history of API activity, enabling security analysis, resource change tracking, and compliance auditing. Supports creating and managing trails, looking up events, querying event data stores, and configuring insights.
