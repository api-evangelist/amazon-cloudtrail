In January 2023, AWS announced the support of ingestion for activity events from non-AWS sources using CloudTrail Lake . Making CloudTrail Lake a single location of immutable user and API activity events for auditing and security investigations. AWS CloudTrail Lake is a managed data lake for capturing, storing, accessing, and analyzing user and API activity on AWS and non-AWS sources for audit, security, and operational purposes.
